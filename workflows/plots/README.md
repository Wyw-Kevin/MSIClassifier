# Scientific plots

```sh
python reproduce.py --branch plots
python reproduce.py --branch spatial --plots
```

Numeric sources generate current bulk Figure4/S1/S2, current uncapped subtype/CNV sensitivity S3, and the combined scRNA screening/evaluation figure. The spatial function generates the paired spot display and section/patient summaries. Retained functions were extracted before document edits; no Word or prior manuscript is required. Scientific data, RNG2026 and original plotted model identities are preserved.

The historical scRNA configuration grid uses whole-epithelial MLH1; current weighted model panels are separately identified. Manuscript-specific panel splitting, labels or literature-comparison vector layout are presentation assets in the separate supplement, not additional executable analysis routines.
