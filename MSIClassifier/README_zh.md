# MSIClassifier使用说明

本文件夹整理当前稿件所需的分析代码、补充资料、模型、小型输入及来源记录。当前为2026年10月14日的本地资料包，未发布至公开仓库或分配DOI。

## 文件安排

补充Word仅放**补充方法、补充图S1–S3及中文图注**。补充表S1–S14及扩展表单独放在英文Excel附件中，逐样本评分和2,000次抽样记录放在`supplement/data_attachments/`及相应分析分支资源目录。目录说明见英文README。

## 直接核对已归档结果

使用Python3.12及`environment/requirements_core.txt`的环境，在本文件夹运行：

```sh
python reproduce.py --branch all
```

也可将`all`替换为`bulk`、`scRNA`、`spatial`、`paired`、`stability`、`bayesprism`或`figures`，分别核对对应部分。新结果写入`output/`，不覆盖留存模型和原始结果。默认流程不重新训练；BayesPrism检查使用合成样本验证实现并核对归档丰度，不重算真实队列。

已归档特征的评分、固定融合、配对增量区间和开发集内选择稳定性可在CPU复现。若要从原始测序表达重新运行，需按`docs/DATA_REQUIREMENTS.md`配置原始h5ad、bulk表达和大型权重，不能将代码包中的小型特征表当作完整原始数据。

## 必须保留的来源区别

单细胞18亚型生态特征沿用较早冻结TOSICA模型；新2026参考仅覆盖其中13个。代码包保留两套模型的字典、掩码和来源，不能用零填补缺失亚型、替换历史测量后仍报告原性能。原主分析五折模型没有逐一保留，另存的q95敏感性重拟合模型可数值复现归档OOF分数，但身份保持分开。

bulk主流程为12亚型MLP＋对应轮次的留一队列MMR4，固定0.5∶0.5融合；留一队列仅指MMR4。空间分支使用重建代理输入向冻结分类器迁移，属于技术可行性评价。详细参数、历史版本缺失及空间参考训练历史限制均已写入补充Word和各分支说明。

本次整理及核对没有重新选择特征、调整融合权重或产生新的独立外部验证。所有当前显式配置种子为2026，历史权重和旧源码保留真实来源。原文章和各历史结果未覆盖。
