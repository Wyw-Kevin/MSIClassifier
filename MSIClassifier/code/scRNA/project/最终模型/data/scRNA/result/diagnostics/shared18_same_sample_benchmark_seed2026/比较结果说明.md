## 如何评价

18亚型＋MLH1在本次回顾性外部比较中优于简单基线的AUROC点估计，但相对大类比例、合并亚型、MLH1单独和MMR4表达的配对差值区间均包含0，尚未证明稳定的外部优越性。训练OOF的历史特征筛选偏倚也不能由本比较消除。

强表达基线在外部队列的点估计更高：训练内部调参的397基因Logistic为0.9737，MSIsensor-RNA伪bulk适配为0.9868，而本模型为0.9211。因此目前不能宣称18亚型框架优于强表达模型。细胞来源解释是模型的结构特点，但其实际使用价值仍需独立数据和具体应用评价支撑，不能用来替代性能证据。

下一步最有信息量的是锁定模型后在未参与历史开发的CRC单细胞队列重复同样本比较，而非继续根据GSE132465选择特征或模型。

## 方法与边界

- Major7：肿瘤样本中B、Epi、Mast、Myeloid、Plasma、Strom、TNKILC占全部肿瘤样本细胞的比例。训练使用原始majorCluster，外部使用原流程TOSICA迁移标签；并非只取恶性细胞。
- Collapsed18：18个既有比例按所属大类求和，保留原71类候选体系中各大类的比例分母。该对照与完整18模型共享历史筛选；它不等同于全体细胞的大类比例。
- MMR4为四基因伪bulk表达的本地Logistic基线，不是之前手工MMR4表达规则。397基因Logistic使用官方CRC基因面板；固定C=1及训练内部选择C两种方案都报告。内层调参只使用训练患者，未根据外部成绩选择。
- 官方MSIsensor-RNA使用冻结TCGA.CRC SVM及397基因；未在这87例上重新训练。官方入口输出与本地向量化输出已核对到其四位小数精度。
- 伪bulk：原始counts按样本求和，重复基因名求和，用全基因文库大小转CPM，再log2(1+CPM)，进入官方模型。
- 逐细胞：397基因检出比例至少20%；不足20个合格细胞时取检出比例最高20个。按样本内各基因的细胞均值填补0，log2后进行官方细胞内标准化，逐细胞预测后取样本均值。另报告log2后填补的敏感性结果。论文未公开完整单细胞预处理入口，因此标为依照论文重建，不声称精确复现其原始结果。
- 逐细胞规则共保留训练20548个、外部766个细胞；训练7/64例、外部12/23例使用top20回退。其预处理依赖性应单独说明。
- 种子2026应用于本地拟合、分组和bootstrap；官方预训练模型的历史参数原样保留，不修改其内部随机状态。
- AUROC比较不需要选分类阈值。本次不依据外部队列反转评分方向、调整权重、筛选亚型或选择超参数。
- 18亚型是历史筛选结果；固定特征OOF不等于完整嵌套筛选验证。当前GSE132465多次用于历史评估，属于回顾性外部比较，不能称全新独立验证。区间仅反映固定预测下的患者抽样不确定性，不包含历史模型选择不确定性。
- 外部仅4例MSI，配对置信区间较宽；本比较没有排除临床混杂，临床敏感性分析另见既有审计。
- 完全排序分离时，非参数bootstrap的AUROC区间可能退化为[1,1]；这不代表总体泛化性能没有不确定性。
- 基线与本模型训练资源不同：官方模型来自TCGA，本地表达基线来自64例单细胞伪bulk。必须如实说明，不能等同于相同训练预算的算法竞赛。
