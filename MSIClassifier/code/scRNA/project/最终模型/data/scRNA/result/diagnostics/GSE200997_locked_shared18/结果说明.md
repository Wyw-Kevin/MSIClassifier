# GSE200997 独立队列分析

数据来自 GEO GSE200997 和原文临床补充表：https://doi.org/10.1186/s13059-022-02677-z 。16例肿瘤患者，其中2例MSI-H、14例MSS；正常组织不作为模型评估样本。

固定现有18亚型及其顺序，使用原有TOSICA权重迁移；亚型比例遵循原始未合并71亚型流程，以对应大类全部细胞为分母。Z-score仅使用GSE178341训练参数。未用新队列筛选特征、调整超参数、方向或阈值。

**MLH1输入限制：** 新队列缺少已确认的恶性上皮细胞标签。本次使用肿瘤组织内TOSICA预测Epi细胞的MLH1均值，属于代理输入，不能称为与历史恶性上皮定义完全一致的独立验证。含该输入的模型均标记为proxy。18亚型独立模型不受这一MLH1代理限制。

所有主表模型在同一组可评估患者比较；all_available列保留各模型全部可评估样本结果。置信区间为2000次分层患者bootstrap，随机种子2026。仅2例阳性，区间不能充分反映更广泛MSI异质性，不据此宣布方法优势。

本队列中18亚型单独模型、18亚型加MLH1代理模型及397基因Logistic（C=1）均为AUROC 0.929。支持细胞生态模型的外部判别能力，但尚未证明优于强表达基线；加入MLH1代理没有增加本队列的AUROC。主要配对差值区间未排除零，不作显著优越性表述。

样本质量：T_cac5仅174个肿瘤组织细胞，其中2个上皮细胞，并缺少两个被建模的大类。它为MSS，却在18亚型加MLH1代理模型中评分最高；两例MSI T_cac7和T_cac12分别排第2和第3位。此现象提示低细胞量输入的稳定性风险，不能据此确认因果关系。主分析保留全部16例，未依据结果排除T_cac5。逐样本细胞组成见sample_cell_QC.csv，排序见shared18_patient_ranking.csv。

简单基线和397基因Logistic仅在原GSE178341拟合。正则化参数沿用此前训练内选择，不在GSE200997重新选择。重建基线先核对GSE132465预测与既有记录一致，见reproduction_checks.csv。MSIsensor-RNA使用官方TCGA.CRC预训练模型；其训练资源不同，不能视为同训练样本预算比较。细胞均值版本为依据论文描述的重建，另列填补顺序敏感性分析，不声称是官方独立单细胞实现。

文件：all_predictions.csv为逐患者全部评分；AUROC_summary.csv为指标；paired_AUROC_differences.csv为同患者配对差值；frozen_protocol.json为冻结规则；clinical_labels.csv为临床标签；PDF为可编辑矢量图。未计算阈值相关错误率、准确率或BA。
