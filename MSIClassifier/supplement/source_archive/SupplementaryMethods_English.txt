Python BayesPrism implementation
The current twelve-subtype matrices originate from the preserved pybayesprism 0.1.0 Python port (ziluwang 829/pyBayesPrism), with archived local correctness and runtime patches. The method is described by Chu et al. (reference 32); the software is reference 37. The exact installation Git commit and historical dependency-version snapshot were not retained. Current installed versions are not substituted for those missing records. Original and modified source files, patch instructions, hashes and parameter records are preserved in the reproducibility archive.

Reference and target inputs
The fixed GSE178341 reference uses layers['counts'], summing repeated gene symbols and retaining 71 non-epithelial labels plus Epi. No per-cell total 10000 normalization or logarithmic transform is applied to this reference. After the recorded filters,17039 genes remain. Each target cohort is processed separately. Logged RSEM expression is inverted with 2**x-1; processed logged microarray expression is inverted with 2**x. The continuous target matrices are archived. Before Prism.new, the complete linear target matrix is converted with numpy.rint(...).astype(int64), including nearest-even rounding of half-integers. This integer matrix is used for initial Gibbs inference, cohort-level reference update and final Gibbs inference, rather than merely rounding a temporary sampling total. Microarray intensity proxies are not RNA-seq read counts.

Sampling and classifier abundance input
The generic mixture branch uses key=None and update_gibbs=True. Chain length is configured as 1000, burn-in 500, thin 2, alpha 1 and MAP sigma 2. The actual preserved loop updates indices 0..998 and retains 250 states,500,502,...,998. All explicitly configured run seeds are 2026. Final posterior-mean abundance is posterior_theta_f.theta, exported as final_fractions.csv. The parent denominator is the sum of all subtypes belonging to the same clTopLevel in this final matrix. The classifier uses subtype abundance divided by this parent sum. Initial fractions and DECODE outputs are not used in the current twelve-subtype classifier.

MMR4 input scale and cutoff ordering
MMR4 takes the four gene values from stored expression.csv matrices before BayesPrism-specific inverse transforms or rounding. TCGA uses log2(RSEM normalized expression+1); the seven GEO cohorts use processed log2 microarray expression. All 4848 archived pre-Z-score values across 1212 samples were matched to those matrix values. Cohort-specific mean and sample standard deviation (ddof=1) are computed without outcome labels. Cutoff candidates are ranked by descending training macro-AUROC rounded to 12 decimals, then descending training macro-BA rounded to 12 decimals, then ascending MLH1/MSH2/MSH6/PMS2 cutoff values. Thus the lexicographically smallest tied vector is retained; rounding is part of comparison, not solely display.

Single-cell units and composition controls
Reported development AUROC uses all 64 specimen predictions directly. Cross-validation groups the 62 patient IDs; outcome-stratified bootstrap samples patient clusters and includes every specimen of a selected patient. The main intervals, paired intervals, S7 control intervals and separate centered posthoc p-values use specimen-level AUROC within these cluster resamples. No patient-mean score aggregation is applied to the reported AUROC. CNV sampling draws 100000 cells from all cells belonging to QC-passing tumor-tissue specimens, before malignant-candidate assignment. S7 reports fraction-only, subtype-plus-fraction, separate mean/fraction and product-weighted controls. No archived direct add-MSH2/MSH6/PMS2 comparison of the current weighted MSI/dMMR classifier was located; a separate stored-MLH1-loss analysis has a different target and does not supply that evidence.

Spatial posterior summaries and expression reconstruction
The reference uses raw counts and 73 fixed types. Its gene pool is the intersection of reference symbols, the first spatial section and a fixed historical bulk-common list;16005 unique symbols precede the reference filter (cell_count_cutoff 15,cell_percentage_cutoff 2=0.03,nonz_mean_cutoff=1.12), which retains 12079 model genes. All 14 sections contain this same ordered set. Cell 2location.export_posterior exports 200 posterior draws. Reconstruction inserts post_sample_means for w_sf,m_g and s_g_gene_add into the official conditional expected per-cell-type count formula; reference signature is means_per_cluster_mu_fg. Abundance is means_cell_abundance_w_sf. These are posterior means, not lower quantiles. Reconstructions are computed from parameter means, rather than reconstructing separately for every draw and then averaging.

Spatial reconstruction formulas
Let X_ig be the observed raw spot count, mu_gf the fixed reference signature, w_if the posterior-mean abundance, m_g the posterior-mean gene scaling, and s_g the posterior-mean additive background. Candidate allocated counts are C_ig = X_ig*(w_i,cand*mu_g,cand*m_g)/(sum_f(w_if*mu_gf)*m_g+s_g). ReconstructedMLH 1_i = ln(1+10000*C_i,MLH1/sum_{g in G}C_ig), where G contains all 12079 filtered model genes. The section feature is sum_i(ReconstructedMLH 1_i*CandidateAbundance_i)/sum_i(CandidateAbundance_i+OtherEpithelialAbundance_i). Thus conditional count allocation precedes candidate-specific CP10K, natural log1p and epithelial abundance weighting. The feature and 18 parent-normalized subtype abundances enter the frozen training scaler and shrinkage LDA; two section probabilities are averaged per patient.

Spatial training records
The 180-epoch reference checkpoint has an empty history_ dictionary and no current-run reference loss trajectory was recovered from retained logs. The is_trained flag does not demonstrate convergence. All 14 section checkpoints contain 500 loss entries matching their saved CSV records. The relative change between the last 50 and preceding 50 loss means is 0.3184%-1.5452%. Finite histories and loss decreases provide optimization diagnostics but do not establish a prespecified convergence criterion. This limitation is retained. Independently replaying 20733 spots from raw 10x counts and saved posterior means reproduced reconstructed log expression within 5.71e-8, weighted section features within 3.07e-9 and frozen probabilities within 2.22e-16; this is computational replay, not measurement-equivalence validation.

Paired fusion-versus-MMR4 AUROC increment
The contrast is AUROC(Fusion 05)-AUROC(MMR4_LOCO), using the same 1212 samples and their corresponding archived cohort-held-out MMR4 cutoff locks. Fusion 05 is 0.5*actual twelve-subtype probability+0.5*MMR4_LOCO. Subtype probabilities are five-fold OOF in the two development cohorts and full-development-model predictions in the six GEO cohorts.2000 outcome-stratified within-cohort sample draws use identical indices for both scores. The existing 2026 advancing RNG stream was independently reproduced; no seed offsets or loop resets were used. TCGA patient identifiers are distinct; GEO patient clustering has not been independently audited, so the unit is bulk sample. At each replicate, cohort differences are averaged equally within each fixed cohort subset; cohorts themselves are not resampled.95% intervals are percentile 2.5/97.5. All upstream measurements, scalers, cutoff locks and classifier predictions remain fixed; no feature selection or fitting uncertainty is included. All 32000 bootstrap component AUROCs were independently checked by weighted positive-negative pair comparisons. Point differences and intervals use unrounded values.
