# Step-by-step usage tutorial

[Main README](../README.md) · [Paper analysis replay](REPRODUCING_ANALYSES.md) · [Input files](INPUT_FILES.md) · [Parameters](PARAMETERS.md)

Run commands from the repository root after installing `requirements.txt`. Paths containing spaces should be quoted. Scoring creates missing output parent directories; it leaves supplied models unchanged.

## First: start with expression data

Use [the complete expression workflow](EXPRESSION_WORKFLOW.md) for bulk gene/probe matrices, scRNA h5ad/10x/loom/text, or raw spatial spot counts. It covers file orientation, scales, specimen/tissue metadata, fixed resources, probe mapping and complete prediction commands. Subtype proportions are generated within these routes.

```bash
python predict.py bulk --expression bulk_expression.csv --scale log2p1 --dataset MY_BULK --output-dir output/new_bulk
python predict.py scrna --expression cells.h5ad --layer counts --scale counts --dataset MY_SCRNA --output-dir output/new_scRNA
python predict.py spatial --expression section.h5ad --layer counts --sample-id sectionA --output-dir output/new_spatial
```

Install the separate frozen reference archive and expression dependencies for scRNA/spatial. Add `--check-only` to inspect inputs before model execution. The sections below are advanced shortcuts for previously generated compatible features and archived analyses; they do not define the first biological input.

## Advanced A. Already measured scRNA features

```bash
python --version
python workflows/scRNA/predict_scrna.py --help
python workflows/scRNA/predict_scrna.py \
  --feature-table examples/scRNA_features.csv \
  --output output/scRNA_scores.csv
```

The example has five GSE132465 specimens with complete features. The expected result is:

```csv
sampleID,score
SMC01-T,0.1193204176720935
SMC02-T,0.0831817820123082
SMC03-T,0.9928815615157992
SMC04-T,0.011646691173059
SMC05-T,0.0024609378150082
```

Compare numeric output to the bundled reference without loading any model:

```bash
python - <<'PY'
import numpy as np
import pandas as pd
observed = pd.read_csv('output/scRNA_scores.csv').set_index('sampleID')
expected = pd.read_csv('examples/scRNA_expected_scores.csv').set_index('sampleID')
assert observed.index.equals(expected.index)
np.testing.assert_allclose(observed.score, expected.score, rtol=0, atol=1e-10)
print('Example scores match')
PY
```

These are stored-input checks, not new validation on independent specimens.

## Advanced B. Score your own scRNA feature table

Prepare a CSV using [examples/scRNA_features.csv](../examples/scRNA_features.csv) as a complete-column template. Required values are measured fractions and verified weighted MLH1, not Z-scores. There is no MSI-label requirement.

```bash
python workflows/scRNA/predict_scrna.py \
  --feature-table my_scRNA_features.csv \
  --output output/my_scRNA_scores.csv
```

If a compatible archived table stores the weighted value under `mean_MLH1_epithelial`, use:

```bash
python workflows/scRNA/predict_scrna.py \
  --feature-table my_verified_weighted_features.csv \
  --weighted-mlh1-column mean_MLH1_epithelial \
  --output output/my_scRNA_scores.csv
```

That alias is appropriate only if its source confirms `mean(candidate MLH1) × N_candidate/N_all_epithelial`. Do not use the alias to pass an old whole-epithelial/raw-MLH1 feature. To select another compatible artifact, supply `--model`; the current interface checks the model's recorded seed/formula and uses its stored feature order.

The expression entry `predict.py scrna` performs raw annotation and CNV estimation. This advanced feature-table shortcut skips those completed steps. In particular, complete fixed 18 measurements cannot be regenerated by silently filling the newer seed 2026 family's five unsupported types with zero.

## Advanced C. Score bulk subtype features

The bulk CSV contains sample identifiers and 12 parent-normalized abundances. Additional MMR genes are optional in subtype-only mode.

```bash
python workflows/bulk/predict_bulk.py \
  --feature-table examples/bulk_features.csv \
  --output output/bulk_scores.csv
```

For your own measured/deconvolved features:

```bash
python workflows/bulk/predict_bulk.py \
  --feature-table my_bulk_parent_fractions.csv \
  --output output/my_bulk_scores.csv
```

This applies the actual full-development model. `dataset` is optional in this mode. When included, uniqueness is assessed on `(dataset,sampleID)`; otherwise `sampleID` must be unique. The input subtype values must be 0–1 parent fractions, not all-cell fractions or screening-sign-flipped values.

## Advanced D. Existing-cohort fixed fusion

Use the GSE24550 lock with the provided GSE24550 rows:

```bash
python workflows/bulk/predict_bulk.py \
  --feature-table examples/bulk_features.csv \
  --mmr4-lock workflows/bulk/mmr4/locks/heldout_GSE24550.json \
  --output output/bulk_fusion.csv
```

For the first row, the archived component values are approximately:

| sampleID | Subtype | MMR4_LOCO | Fusion 05 |
| --- | --- | --- | --- |
| GSM712398 | 0.199480 | 0.042346 | 0.120913 |

The complete reference output is [bulk_expected_fusion.csv](../examples/bulk_expected_fusion.csv). The scorer uses the lock's cohort mean/sample-SD, applies its four thresholds, then combines scores at 0.5/0.5. It does not estimate normalization from this five-row subset.

An unmatched cohort lock raises an error. Supplying another name for a new cohort does not define its MMR4 calibration. Unknown cohorts can use the subtype branch; a deployment fusion protocol requires an independently defined threshold/normalization lock.

## Advanced E. Reproduce the stored-input analyses

```bash
python reproduce.py --branch all --output-dir output/replay
```

The dispatcher runs seven analysis branches in sequence, stops on an unsuccessful command and writes `<branch>.log` plus `summary.json`. It uses stored measurements and checkpoints; it does not train models or recompute raw annotation/CNV/posteriors. In `bayesprism` mode it verifies the reference and a synthetic mixture, rather than processing the real cohorts.

Individual tasks:

```bash
python reproduce.py --branch bulk
python reproduce.py --branch scRNA
python reproduce.py --branch sensitivity
python reproduce.py --branch spatial
python reproduce.py --branch paired
python reproduce.py --branch stability
python reproduce.py --branch bayesprism
```

The bulk replay covers 1,212 samples using development OOF and retrospective full-fit probabilities. The scRNA replay checks the frozen scores, patient-grouped evaluation, controls, patient bootstrap and rho/VIF. The sensitivity verifier checks 42 separately identified models and 1,660 scores. Spatial replay covers 14 sections/7 patients. Pairing and bootstrap use the archived sample/patient IDs and the recorded 2026 RNG streams.

Bulk full-fit direct scores and development OOF replay scores are different quantities. Original primary scRNA fold objects were not saved; separately identified q 95 sensitivity refits reproduce archived OOF scores without changing their identity.

## Advanced F. Generate numerical figures

```bash
python reproduce.py --branch plots
python reproduce.py --branch spatial --plots
python reproduce.py --branch all --plots --output-dir output/replay_with_figures
```

Figures include current bulk composition/MMR4 components and selection stability, scRNA subtype/CNV sensitivity, historical configuration screening/current weighted-model evaluation, and paired spatial displays. The spatial display mask and color clipping affect presentation, not model inputs. Fontconfig is required for the paired spatial font lookup.

## Advanced G. Optional refit from archived bulk features

This is classifier refitting on stored measurements, not fresh BayesPrism inference:

```bash
python workflows/bulk/classifier_snapshot/run_analysis.py \
  --replay --output output/bulk_refit
python workflows/bulk/classifier_snapshot/verify_analysis.py output/bulk_refit
```

The run preserves the 7/12 comparison, fixed seed/configuration and the historical 10 numerical control used by its integrity check. New fitted artifacts are written to the specified output directory. The historical 10 control is not the primary prediction model. Standardization is fitted within training folds; source screening/full-development panel selection remains fixed and outside CV.

Always specify a new `--output` directory and `--replay`. The original defaults point to the script directory and historical source layout, which are not the intended publication-run destinations.

## Advanced H. Optional scRNA sensitivity refit

```bash
python workflows/scRNA/resources/article/scRNA_AUROC_threshold_all_candidates_seed2026_20261013/run_analysis.py \
  --output-dir output/scRNA_sensitivity_refit
python workflows/scRNA/resources/article/scRNA_AUROC_threshold_all_candidates_seed2026_20261013/verify_analysis.py \
  --analysis-dir output/scRNA_sensitivity_refit \
  --output output/scRNA_sensitivity_refit_checks.json
```

This reuses the stored patient folds and candidate ranking. Thresholds 0.60/0.65/0.70/0.75 include all passing 39/24/17/9 subtypes; the fixed 18 historical reference is separate. CNV q 90/q 95/q 99 features are supplied measurements, with refitted and frozen-q 95 classifier modes. It does not infer new CNV or tune a threshold on retrospective AUROC.

## Advanced I. Fresh real-cohort BayesPrism run

This optional stage requires the additional raw files described in [INPUT_FILES.md](INPUT_FILES.md#6-bayesprism-raw-input-layout). The current preparation script needs the original reference h 5ad, even though its count summary is bundled.

```bash
export MSI_PROJECT_ROOT=/path/to/input_project
export MSI_BAYESPRISM_WORKDIR=/path/to/new_bayesprism_run
export MSI_BAYESPRISM_COHORTS=current8
python workflows/bayesprism/prepare.py
```

Run one cohort sequentially with four workers:

```bash
python workflows/bayesprism/run_cohort.py GSE24550 4
python workflows/bayesprism/postprocess.py
```

Alternatively, run the supplied fixed launcher after preparation:

```bash
python workflows/bayesprism/launch.py
python workflows/bayesprism/postprocess.py
```

The launcher uses three simultaneous cohorts and 24 workers per cohort. For a smaller machine, use the sequential positional-worker command instead. Only completed cohorts are exported by postprocessing. Sample-level cached tasks and `complete.json` enable resuming a compatible run; use a new work directory for another input/configuration.

The main abundance output is `cohorts/<DATASET>/final_fractions.csv`; postprocessing creates `exports/subtype_over_major.csv`. These are updated-reference posterior means. Four-gene MMR4 inputs continue to come from the original log matrices, not these abundance files or rounded sampling matrices.

## Advanced J. Interpret results in their intended scope

Direct scores are continuous outputs. The paper's 0.5 decision threshold is an evaluation convention, not evidence of clinical probability calibration in a new population. Frozen-input replay verifies computations; upstream feature selection, annotation and cohort adaptation are not repeated inside every CV fold. Cohorts previously examined remain retrospective. Spatial reconstructions are proxies rather than established equivalents of measured single-cell features.
